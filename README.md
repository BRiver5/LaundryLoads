# Laundry Loads

Fewer loads, nothing runs out, no pink socks. A local-only laundry planner: drop
items into the hamper as you take them off; the app sorts them into the fewest
safe loads, plans the wash week around your drying rack so towels and gym wear
never run out, and learns which color mixes are safe from your reports.

## Run

```
npm install
npx expo start
```

`npm run verify` — typecheck, unit tests, project rules, offline export.
