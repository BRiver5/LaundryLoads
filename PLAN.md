# Laundry Loads — План реализации

> «Fewer loads, nothing runs out, no pink socks.»
> Корзина белья раскладывается в минимальное число безопасных стирок, неделя
> планируется так, чтобы полотенца и спортивная форма не кончались, а модель
> прокраса учится на отчётах «полиняло / всё чисто».

## 0. Архитектура и разрешения
Полностью локальное, `expo-sqlite`. `expo-notifications` удалён. `VIBRATE` —
вибрация (выключается). INTERNET и всё чувствительное — в `blockedPermissions`.

## 1. Дизайн
`#1B526A` — синий ополаскивателя; фон `#EFF4F3`; пена `#4FA3B8`, коралл
`#C9573F` (прокрас/опоздание), свежесть `#2F8A5E`. Архетип — **Focus
Single-Card**: одна крупная карточка «стирка N» с барабаном, между стирками
недели — горизонтальный свайп.

## 2. Модель данных
| Таблица | Поля |
|---|---|
| types | id, name, color (white/light/dark/bleed), care, max_temp, want_temp, kg, dryer, owned |
| hamper | type_id, pieces |
| adds | id, day, type_id, pieces — журнал «в корзину» для темпа |
| washes | id, day, entries (json), temp, kg, ran (отчёт о прокрасе) |
| model | bleed / rates / rateDay (json) |
| settings | capKg, loadsPerDay, rackKg, dryer, haptics, extra:<date>, model_version |

## 3. Движок (`src/lib`)
- `laundry.ts` — совместимость пар: жёсткие запреты (белое + тёмное и т.п.,
  порог 50% риска), мягкие штрафы (недостир при холодной стирке, деликатный
  режим для обычных вещей, риск прокраса); накапливаемая бета-модель прокраса
  по парам цветовых групп с забыванием.
- `packer.ts` — точное разбиение корзины на загрузки: ДП по маскам с перебором
  подмасок, содержащих младший элемент; тяжёлые типы режутся по вместимости.
  Сверено перебором всех разбиений в тестах.
- `schedule.ts` — темп износа (гамма-пуассон по закрытым дням) → день, когда
  кончится чистое → дедлайн стирки; точный перебор с отсечением «загрузка →
  день» под лимит стирок в день и стойку для сушки; исправления опозданий,
  проверенные перерасчётом (ещё стирка в день X, сушилка, вторая стойка).

## 4. Экраны (6)
`index` (карточка стирки, свайп по неделе), `hamper` (корзина и гардероб),
`item/[id]` (запас, уход, с чем нельзя), `plan` (Week / What if), `stats`, `settings`.
